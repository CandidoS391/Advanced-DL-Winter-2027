# Notebooks

This directory contains the weekly interactive notebooks used throughout the project, and demoed during project meetings. The notebooks here will help reinforce the concepts presented in the slides by showcasing how it is built, and how it can be applied to help build up the overall neural network architecture.

Since the notebooks are meant to correspond to that week's slides, each weekly notebook will be sent out to this repository before each meeting so that participants fully know what the week's agenda is.
