## Overview

This is the repository for the Winter 2027 ACM DAS advanced project: Seeing the World Using Computer Vision. This 8-10 week project introduces participants to the mathematical foundations and practical implementation of deep learning, with an emphasis on neural networks and computer vision. Through guided explanations and interactive demonstrations, participants will explore concepts such as neural network architectures, forward propagation, backpropagation, convolutional neural networks (CNNs), training, regularization, and model evaluation.

After developing these foundations, participants will pursue independent projects in which they select their own datasets, implement neural network models, and investigate questions of their choosing. Participants are encouraged to experiment with different architectures, training strategies, and evaluation methods while developing an understanding of how deep learning models behave in practice.

The project emphasizes curiosity, experimentation, and technical understanding rather than simply achieving high accuracy. It also introduces participants to good scientific practices, including documenting methodologies, interpreting results, and discussing limitations. Although formal research experience is not required and publication is not an expectation, the project can serve as a stepping stone toward more advanced machine learning work and future research opportunities. 

All materials used during project meetings (i.e slides, notebooks), as well as additional resources (challenges, references, and eventually sample reports) are included here based on the listing of the directory (for instance, all slides for the meetings are posted in the slides directory). Essentially, everything you may need while developing your CNN project will live here, while all communications will go through on the ACM DAS Discord. 

## Prerequisites and Expectations

This project was primarily designed for those who have basic knowledge of machine learning, data science, and programming techniques (i.e the skills built up in the DAS' beginner and intermediate projects). Whilst the project leads will welcome and try to accommodate everyone on all levels of experience, it is with this in mind that they will expect project members to be familiar with the following:
- Programming: Familiarity in at least one programming language, including familiarity with functions, data structures, and basic debugging.
- Data Science: Familiarity with data preprocessing, exploratory data analysis, working with datasets, and interpreting results.
- Machine Learning: Familiarity with fundamental concepts such as supervised learning, training and testing datasets, loss functions, and model evaluation.

Additionally, but not required, it is highly recommend some familiarity with some math concepts vital to deep learning, mainly calculus, linear algebra, and probability/statistics. Underneath the underlying framework, these concepts help power the machinery of neural networks, and so having an elementary understanding of the following certainly helps:
- Linear Algebra: Familiarity with vectors, matrices, matrix multiplication, linear transformations, and basic matrix operations.
- Calculus: Familiarity with derivatives, the chain rule, gradients, and basic multivariable calculus (Partial Derivatives and Gradients).
- Probability and Statistics: Familiarity with probability distributions, expected values, variance, descriptive statistics, and basic statistical analysis.

Finally any preexisting knowledge or work with deep learning is certainly welcomed, but is not expected. Above all, participants are expected to be active in the project, be able to learn new concepts, seek clarification if needed, and most importantly be a positive figure for all in the project.
