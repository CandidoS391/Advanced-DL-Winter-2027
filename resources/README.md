# Resources

This directory contains supplementary materials intended to support participants throughout the workshop. These resources provide mathematical references, programming guidance, and additional learning opportunities beyond the weekly sessions.

## Available Resources

| Resource                 | Description                                                                                                 |
| ------------------------ | ----------------------------------------------------------------------------------------------------------- |
| Mathematical Notation    | Reference for the mathematical symbols and conventions used throughout the workshop.                        |
| Mathematical Foundations | Review of relevant linear algebra, calculus, and probability/statistics concepts.                           |
| Introduction to PyTorch  | Interactive introduction to tensors, automatic differentiation, neural network modules, and model training. |
| Additional References    | External documentation, textbooks, tutorials, and other recommended learning materials.                     |

## Using These Resources

These materials are intended to supplement the workshop rather than replace its instructional sessions.

Participants are encouraged to consult them whenever they encounter unfamiliar concepts or wish to explore a topic in greater depth. Prior mastery of every resource is not expected.
